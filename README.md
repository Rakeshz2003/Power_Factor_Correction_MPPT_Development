Project Description

Development of a solar PV-based Maximum Power Point Tracking (MPPT) system using a DC–DC converter to maximize power extraction from the photovoltaic panel. Implemented control logic using PV voltage and current feedback to dynamically adjust the converter duty cycle and track the maximum power point.

Key Development Activities
- Studied solar PV characteristics and maximum power point behaviour.
- Developed MPPT control algorithms using PV voltage and current feedback.
- Implemented duty-cycle control for DC–DC converter operation.
- Modelled and simulated the MPPT system using MATLAB/Simulink.
- Analysed converter response under varying solar irradiance and load conditions.
- Performed hardware implementation and bench-level validation.

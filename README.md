Project Description

Development of a solar PV-based Maximum Power Point Tracking (MPPT) system using a DC–DC converter to maximize power extraction from the photovoltaic panel. Implemented control logic using PV voltage and current feedback to dynamically adjust the converter duty cycle and track the maximum power point.

Key Development Activities
- Studied solar PV characteristics and maximum power point behaviour.
- Developed MPPT control algorithms using PV voltage and current feedback.
- Implemented duty-cycle control for DC–DC converter operation.
- Modelled and simulated the MPPT system using MATLAB/Simulink.
- Analysed converter response under varying solar irradiance and load conditions.
- Performed hardware implementation and bench-level validation.
  
1. 400 W Power Factor Correction (PFC) Converter
   
Project Description
Design and development of a 400 W PFC converter using the NCP1653 controller IC. The project focuses on the PFC power stage and its control, sensing, feedback, and protection circuits, with the aim of improving input power factor and supporting regulated DC-bus operation.
Key Development Activities
•	Studied the NCP1653 controller architecture, application circuit, and key operating parameters.
•	Worked on the PFC power-stage design and selection of the inductor, switching device, rectifier, and DC-bus capacitors.
•	Developed and reviewed voltage-feedback, current-sensing, and protection circuitry.
•	Performed circuit analysis and simulation to evaluate expected operating behaviour.
•	Supported schematic and PCB development for the PFC stage.
•	Carried out hardware bring-up, switching-waveform observation, and electrical performance checks.

2. 6.6 kW Power Factor Correction (PFC) Converter

Project Description
Design and development of a 6.6 kW PFC converter based on the FAN9673 controller IC. The project addresses high-power PFC implementation, including power-stage design, control and sensing circuits, component selection, and evaluation of converter operation and DC-bus regulation.
Key Development Activities
•	Studied the FAN9673 controller architecture, control features, and recommended application circuit.
•	Worked on the high-power PFC power-stage design and selection of power components.
•	Evaluated inductor, semiconductor, rectifier, and DC-bus capacitor requirements.
•	Developed and reviewed current-sensing, voltage-feedback, and protection circuits.
•	Performed circuit analysis and simulation to assess switching behaviour and component operating stresses.
•	Supported hardware development, testing, waveform analysis, and performance evaluation.
